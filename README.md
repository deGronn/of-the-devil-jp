## 導入方法

zipを解凍し、**3つの方法のうちどれか1つ**を実行してください。どれを選んでも結果は同じです。

### 方法1: `インストール.bat`（おすすめ）

ダブルクリックするだけです。Steamの登録情報からゲームの場所を自動で探すので、
表示された場所で合っていれば、**何も入力せずに Enter を押してください**。

見つからなかった場合や、別の場所に入れている場合は、フォルダを入力します。
エクスプローラからフォルダをウィンドウへ**ドラッグしても入力できます**。

### 方法2: `インストール.exe`

ダブルクリックすると、自動で見つけた場所を提示するので、合っていれば「はい」を選びます。
違う場合は「いいえ」を選ぶと、フォルダを選ぶ画面が開きます。

> **初回起動時に「Windows によって PC が保護されました」と表示されます。**
>
> これはコード署名証明書を付けていないためで、異常ではありません。
> 実行するには `詳細情報` → `実行` の順にクリックしてください。
>
> 警告を避けたい場合は、方法1の bat をお使いください。処理内容は同じです。

### 方法3: PowerShell

```powershell
PowerShell -ExecutionPolicy Bypass -File .\INSTALL_JP_MOD.ps1 -GameRoot "ゲームフォルダのパス"
```

### ゲームフォルダの場所

`of the Devil.exe` があるフォルダです。Steam版の既定では以下にあります。

```
C:\Program Files (x86)\Steam\steamapps\common\of the Devil
```

Steamライブラリでゲームを右クリック →「管理」→「ローカルファイルを閲覧」でも開けます。

## アンインストール（元に戻す）

導入時に、上書きされるファイルが自動でバックアップされます。

```
（ゲームフォルダ）\_OfTheDevilJP_Backups\（日時）\
```

復元するには、そのフォルダ内の `RESTORE_JP_MOD.ps1` を実行します。

```powershell
PowerShell -ExecutionPolicy Bypass -File "（バックアップフォルダ）\RESTORE_JP_MOD.ps1" -BackupDir "（バックアップフォルダ）"
```

完全に取り除きたい場合は、ゲームフォルダから以下を削除してください。

- `BepInEx`
- `dotnet`
- `winhttp.dll`
- `doorstop_config.ini`
- `.doorstop_version`

Steamの「ゲームファイルの整合性を確認」でも、ゲーム本体は元に戻せます（MODのファイルは手動削除が必要です）。
